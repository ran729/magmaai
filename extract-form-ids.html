🔥 Google Form Entry ID Extractor

Instructions:

1. Open your Google Form in a new tab: Click here
2. Press F12 to open Developer Tools
3. Go to the Console tab
4. Copy and paste the script below into the console
5. Press Enter

Copy this script:

// Extract all entry IDs from Google Form const entries = {}; document.querySelectorAll('[name^="entry."]').forEach(input => { const label = input.closest('[role="listitem"]')?.querySelector('[role="heading"]')?.textContent || input.getAttribute('aria-label') || 'Unknown'; entries[label.trim()] = input.name; }); console.log('Entry IDs found:'); console.table(entries); console.log('\nCopy this to your WaitlistForm.tsx:'); console.log(`const FORM_ENTRY_IDS = { name: "${entries['Your Full Name'] || 'ENTRY_NOT_FOUND'}", company: "${entries['Company Name'] || 'ENTRY_NOT_FOUND'}", email: "${entries['Work Email Address'] || 'ENTRY_NOT_FOUND'}", };`);

Alternative: Manual Method

1. Open the form and right-click on the first input field
2. Select "Inspect"
3. Look for name="entry.XXXXXXXXX" in the highlighted HTML
4. Repeat for each field and note down the entry IDs
